# Обзор

Панель — локальный (или Docker) админ для **своих** аккаунтов короткого видео. Автоматизация площадок нарушает их правила: ответственность на операторе.

## Площадки

| Площадка | Тип поста по умолчанию | Клиент |
| --- | --- | --- |
| Instagram | `reel` (ещё `feed_photo`, `feed_video`) | `instagrapi` → `i.instagram.com` |
| YouTube Shorts | `youtube_short` | Playwright на `studio.youtube.com/channel/upload` |
| TikTok | `tiktok` | Playwright на `tiktok.com/tiktokstudio/upload` |

Официальные API (Instagram Graph, YouTube Data API, TikTok Content Posting) и OAuth **не подключены**. Нет квоты Data API и нет «подключить канал через Google».

## Три разных «агента»

Их путают из‑за слова «агент» в UI.

1. **Нижний чат** («Спросить агента») — локальная Ollama (`AGENT_BASE_URL`, обычно `qwen3:8b`) + tools. Пишет в ту же SQLite, что кнопки. Живой браузер из этого чата **не** стартует.
2. **Воркер очереди** — процесс `run-worker` (или баннер/тумблер «Агент работает» / «Агент остановлен»). Берёт `PostJob`, рендеры fal, склейки, контент-планы. Не чат и не страница `/agent`.
3. **Страница «Агент»** (`/agent`, заголовок «Контент-агент») — постановка `PlanJob`: бриф, источники, сколько роликов. Модель контент-плана — не нижний чат.

Автономный текст без UI: `POST /api/assistant/run` и `python -m app.cli ask` — та же Ollama, но с Playwright-tools. См. [assistant.md](assistant.md).

## Прокси

Прокси в панели — **только** для аккаунтов Instagram / YouTube / TikTok (IP, гео, health-check). Они **не** для Ollama, не для «подключить чат к интернету» и не для fal (у fal свой ключ).

Публикация **требует** назначенный прокси. Один аккаунт — один прокси в карточке (сменить можно).

## Пайплайн публикации

`PostJob` в очереди → uniquify (ffmpeg) → неофициальный клиент площадки → backoff при ошибках. Лимиты аккаунта: дневной кап, пауза между постами, часы активности, cooldown.

## Что панель не делает

- Удаление через чат (аккаунты, ролики, операторы — только UI, где есть кнопка).
- Restore бэкапа из чата; в UI «Обслуживание» тоже нет restore.
- Загрузка файлов с диска оператора через чат (DropZone в библиотеке).
- Смена секретного пути и мастер-пароля из чата.
- Поле «Контекст» Ollama из чата.
- Живой VNC из нижнего чата (из `run` / `cli ask` — `start_browser`).
