# UI smoke (ручная проверка)

Короткий чеклист после изменений интерфейса. Viewport: **390px** и **1280px**.

1. **Палитра** — `Ctrl+K`: переход на страницу, повторное открытие — блок «Недавние».
2. **Подтверждения** — удаление медиа / остановка воркера / отзыв оператора — `ConfirmDialog`, не системный alert.
3. **VNC** — Accounts или чат: при активной сессии backdrop не закрывает; «Закрыть браузер» в confirm. Setup сессии — то же.
4. **Свёрнутый агент** — pill «Пишет» / «Думает» на кнопке «Агент».
5. **Mobile nav** — меню: Tab циклически внутри drawer; Escape закрывает, фокус на «Меню».
6. **Loading** — Библиотека и Панель: заголовок страницы виден до данных, не пустой экран.
7. **prefers-reduced-motion** — в DevTools: нет лишних анимаций sparkle/caret/строк.
