# Страницы панели

Авторизация: владелец (`ADMIN_TOKEN` / мастер-пароль) или оператор (страница «Доступы»). Чат и кнопки пишут в одну SQLite.

Нижний блок «Спросить агента» есть на страницах панели. Он **не** страница `/agent`.

## Панель `/`

Сводка: активные аккаунты, исправные прокси, в очереди / в работе, мёртвые задачи. Карточки «Сегодня по аккаунтам», «Последние события». Пусто: «Сегодня активности пока нет.», «Событий пока нет.» Ошибка: «Не удалось загрузить панель», «Повторить».

В шапке тумблер воркера: «Старт» / «Стоп», статусы «Агент работает» / «Агент остановлен» — это **воркер**, не чат.

Чат: `overview`, `diagnose`, `list_errors`, `start_worker`; `stop_worker` после подтверждения. Контекст Ollama не меняет.

## Аккаунты `/accounts`

«Добавить аккаунт», «Добавить прокси». Карточка прокси: «Обновить», пусто «Прокси пока нет.», у строки «Изменить», «Удалить», «Проверить». Аккаунты: «Проверить все», пусто «Аккаунтов пока нет.» У строки: Профиль, Браузер, Подключение, Сессия, TOTP, «Сменить прокси», «Пауза» / «Возобновить», тумблер «проверка» (`hold_for_review`).

Модалка аккаунта: «Отмена», «Сохранить аккаунт». Площадка Instagram / YouTube Shorts / TikTok, имя, пароль, логин Instagram, строка аккаунта, backup-коды, прокси, часовой пояс, дневной лимит, мин. пауза, часы активности, профиль подписей, TOTP, email, заметки. Без прокси: «Нет прокси. Сначала добавьте.»

Модалка прокси: метка, URL `http://user:pass@host:port`, страна, TZ, заметки, «Пропустить проверку при сохранении».

Модалка «Сессия»: Instagram — sessionid, файл cookies, fingerprint, экспорт; YouTube/TikTok — файл cookies и Playwright state, без sessionid/fingerprint. Автовход и mint — модалка «Подключение», только Instagram. «Мобильный» / «Десктоп» — `login_surface` для браузера и `first_login` (Instagram).

Чат создаёт/обновляет аккаунты и прокси, не удаляет, не открывает VNC. Run-endpoint может `start_browser`. Подробнее: [accounts-sessions.md](accounts-sessions.md).

## Библиотека `/publishing`

«Сгенерировать / склеить»: промпт для рендера, «Рендер», «Склеить». DropZone «Перетащите готовые Reels (.mp4)», «Не сжимать». Вкладки видео/фото, поиск, «Снять выбор», «Скачать ZIP», «Быстрая публикация». Превью: аккаунт, тип (Reels / фото ленты / видео ленты / Shorts / TikTok), слот, подпись / заголовок / описание / теги, «Удалить», «Скачать», «Опубликовать сейчас» / «Запланировать», «Обновить статистику».

Чат: клипы, рендер, склейка, очередь и `publish_now`. Не DropZone, не ZIP, не удаление файлов.

## Агент `/agent`

Заголовок «Контент-агент». Карточка «Мануал» и живая полоса подсказки (нет аккаунтов, пустой бриф, вопросы, постановка, выключенное расписание). Тумблер воркера «Запустить» / «Остановить». Поля: аккаунт, пресет, бриф, сколько роликов, длительность (с), «Сразу ставить в расписание». «Запланировать», «План на неделю», «Превью». Источники URL, «Добавить», «Проверить». Вопросы: «Ответ» / «Ответить». Таблица прогонов.

Чат: `plan_account`, `preview_plan`, `add_source`, `check_source`, `answer_question`. Модель Ollama здесь не выбирает.

## Рендеры `/renders`

«Новый рендер»: статусы движков, промпт, селект бэкенда (Авто), аккаунт или «без аккаунта», «Поставить рендер». Таблица рендеров (колонка бэкенда и `$` = `cost_usd` fal): отмена / повтор. Склейки: id клипов, «Склеить», отмена / повтор. Оплата GPU/fal — [costs.md](costs.md).

## Календарь `/calendar`

Неделя, карточки слотов, перенос даты мышью. Кнопки «создать день» нет.

Чат новые слоты — `enqueue_publish` / `plan_account`; дату — `reschedule_job`. Drag сам не делает.

## Активность `/activity`

«Обновить сейчас». Полосы публикации / рендеры / склейки. «Одобрить», «Отменить», «Повторить». Модалка логов `#id`.

## Обслуживание `/maintenance`

Ollama: поле «Контекст», «Применить». «Копии базы»: «Снять копию», список. Restore в UI нет. Тумблера воркера нет (он в шапке / на Агенте).

Чат: `diagnose`, `take_backup`. Контекст не меняет.

## Доступы `/operators` (владелец)

«Метка оператора», «Сгенерировать пароль», «Отозвать». Пароль показывается один раз («Копировать пароль»).

Чат только `list_operators`. Создать/отозвать — объяснить и открыть страницу.

## Настройки `/settings` (владелец)

Секретный путь: копировать, «Новый путь», текущий мастер-пароль, «Сохранить путь». Мастер-пароль: текущий / новый / подтверждение. Чат поля не меняет.

## Администрирование `/administration` (владелец)

Вкладки: «Обзор» (GPU Salad Start/Stop через Salad Public API `GET/POST /api/gpu` — не тумблер воркера; Running = GPU-часы; без `SALAD_API_KEY` кнопки выключены; при `SALAD_IDLE_STOP_MINUTES` > 0 группа сама Stop после простоя, Start снова качает образ; «Оплата»; «Реализация»), «Блокнот» (одна заметка в SQLite `panel_settings.admin_notes`, автосохранение; чат не читает и не пишет; не класть пароли и ключи — они в `.env`), «API» (Swagger по `/api/openapi.json`, Try it out в живой API, Bearer из сессии). `/api/docs` нет. В открытом режиме без пароля вкладка есть. Оператору скрыта.
